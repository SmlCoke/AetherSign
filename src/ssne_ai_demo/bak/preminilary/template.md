# Prompt

## 任务背景

本文件夹是一个端侧设备（单核 CPU + NPU）的应用程序源代码仓库。该应用程序是一个中文手语识别系统，主要功能是：

1. 通过摄像头采集视频帧；
2. 使用 palm detector 检测手掌位置；
3. 使用 hand landmarker 检测手部关键点（可选，目前精度极低）；
4. 将关键点序列用 TCN 模型进行时空建模，进行孤立词分类（暂未部署）；
